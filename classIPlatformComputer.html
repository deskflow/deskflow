Detailed Description

Computer interface.

This interface defines the methods common to all platform dependent comptuer implementations that are used by both primary and secondary comptuers.

Leave computer.

Called when the user navigates off the computer. Returns true if the leave can proceed. A typical reason for failure is being unable to install the keyboard and mouse snoopers on a primary computer. Secondary computers should not fail.

◆ handleSystemEvent()

virtual void IPlatformComputer::handleSystemEvent ( const Event & event)
protectedpure virtual

Handle system event.

A platform comptuer is expected to install a handler for system events in its c'tor like so:

m_events->addHandler(EventTypes::System,
m_events->getSystemTarget(),
[this] (const auto &e) {handleSystemEvent(e);});

It should remove the handler in its d'tor. Override the handleSystemEvent() method to process system events. It should post the events IComputer as appropriate.

A primary comptuer has further responsibilities. It should post the events in IPrimaryComptuer as appropriate. It should also call onKey() on its KeyState whenever a key is pressed or released (but not for key repeats). And it should call updateKeyMap() on its KeyState if necessary when the keyboard mapping changes.

The target of all events should be the value returned by getEventTarget().

Implemented in deskflow::EiComputer, MSWindowsComputer, OSXComputer, PlatformComputer, and XWindowsComputer.
